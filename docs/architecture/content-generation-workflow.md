# 商品内容生成与版本工作流

内容工坊通过平台适配器读取商品事实，使用结构化 `LocalizedListing` Schema 生成标题、卖点、描述、营销文案、FAQ、SKU 文案和关键词。业务层不直接依赖 Mock Shopee。

默认模型网关为明确标记的 `offline_template`，用于无密钥演示；它不代表真实 LLM 调用。网关协议保留真实模型实现入口，生成记录会保存 provider、model、输入摘要、输出、耗时、状态和错误信息。

离线模板覆盖公共契约冻结的 9 种目标语言和 8 个站点代码，不调用外网或翻译供应商；“本地化”仅表示受控模板文案，不表示达到人工翻译质量。

内容工坊允许对标题、卖点、详情、营销文案和 FAQ 单项重新生成。离线模式下该操作会重新执行确定性模板，因此相同输入通常得到相同结果；配置真实模型网关后才可能产生更丰富的改写。标题、卖点、详情、营销文案、FAQ 和 SKU 文案支持人工编辑。

生成结果最多经过三轮模拟站点标题长度、目标语言脚本、商品事实、SKU、请求关键词、关键词重复/堆砌、禁用与夸大宣称和完整性检查。事实检查接受 `6-in-1` 与“6合1”等受控本地化等价写法，并检查 FAQ、SKU 文案中的未经来源支持的技术参数、兼容性、实测和性能宣称。未通过检查的结果会携带具体问题进入下一轮，且页面会如实展示最终检查结论。

“Shopee 站内关键词优化”在首版中是可测试的 Mock 规则：指定词正文覆盖、标题自然包含至少一个指定词、建议词去重和关键词堆砌限制。标题采用各 Mock 站点统一 120 字符的保守内部上限。它不读取真实 Shopee 搜索排名、流量或实时平台规则，也不代表真实 SEO 排名保证。

用户输入并不默认可信。容量、功率、材质、认证、保修、防水、续航等事实型关键词若无法从商品资料中核验，会作为输入问题直接拦截，不再要求模型强行覆盖，也不会重复派生“正文未覆盖”和“标题未包含”问题。此类输入问题不会浪费后续质量重试。

最终用于商品内容的“目标市场关键词”跟随目标语言。另设面向中国运营人员的“中文选词建议”，它始终使用简体中文，只有数据库中的品牌、产品型号、SKU 和 USB-C、HDMI 等技术标识允许保留原文。两者不会混用，保存版本仅保存实际投放的目标市场关键词。内容版本导出面向人工阅读，默认使用 Markdown，而内部 API 与持久化快照继续使用结构化 JSON。

中文选词建议是非发布辅助信息，不参与草稿保存门禁。模型未按要求返回中文时，服务端会对受控电商词进行中文化，并丢弃无法可靠转换的建议，不会用多条辅助信息错误阻塞已经合格的商品内容。

当用户用中文输入关键词、目标市场为非中文时，质量检查在“中文选词建议”中核对用户意图，在目标市场关键词和标题中核对对应的本地化投放词，不做跨语言逐字匹配。

生成是只读操作。保存草稿时，Service 不信任客户端携带的旧质量结论：它会校验生成任务与模型调用归属、比对输入摘要、重新通过适配器读取商品事实，并对人工编辑后的结构化内容再次检查。保存草稿和恢复历史版本均先创建 `ConfirmationTask`，仅在用户确认后写入 `ProductContent` 与不可变的 `ProductContentVersion`。取消确认不会写入内容版本。

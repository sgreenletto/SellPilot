# 智能选品前端工作台

## 范围

`/market/selection` 已由占位页替换为正式智能选品工作台。页面只通过
`frontend/src/api/selection.ts` 调用 `/api/v1/selection`，不读取静态结果数组、不直接
调用 `fetch`，也不访问真实 Shopee。

工作台覆盖：

- 站点、类目、价格、成本、物流成本、最低利润、最低利润率、平台费率、其他成本、重量和风险偏好；
- 正式候选查询、选择和输入边界校验；
- 排名、总分、数据完整度、数据来源、利润与七项评分；
- 结构化解释、证据和风险提示；
- 详情抽屉、2–4 项结果对比；
- 后端 JSON 报告导出和校验和提示；
- 加载、空数据、接口错误、超时、未认证和“后端未连接”状态。

## 状态策略

站点、类目、价格、成本和风险偏好等可复现筛选条件写入 URL query，刷新页面后能够恢复。
候选勾选、分析结果、详情和对比属于短期交互状态，不写入 URL 或全局 Pinia，避免把大型结果
或用户临时选择长期保存。

## 计算边界

成本与物流覆盖值会进入后端确定性利润公式。风险偏好对应版本化评分权重：

- `conservative`：提高利润、物流与售后权重；
- `balanced`：使用 `selection-v1.0.0` 默认权重；
- `growth`：提高需求和竞争权重。

商品重量会透明保存进分析任务条件。当前 Mock 数据没有重量运费阶梯，因此页面明确说明重量
暂不改变评分，不用硬编码系数伪造影响。

## 响应式和可访问性

- 桌面端采用条件栏与结果区双列；
- `<1100px` 改为单列，条件栏取消 sticky；
- `<768px` 表单、候选和指标改为单列，抽屉占满可视区域；
- 选择项使用原生 checkbox，按钮和关闭控件具有文字或 `aria-label`；
- 状态同时使用文字、图标和结构表达，不只依赖颜色。

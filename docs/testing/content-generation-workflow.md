# 商品内容生成测试

验证范围包括：

- 结构化内容 Schema 与确定性质量检查；
- 事实缺失、SKU 缺失、请求关键词覆盖、无事实支撑的用户关键词及免重试、标题关键词、关键词去重/堆砌、Mock 站点标题限制、目标语言脚本、禁用宣称和质量重试；
- `6-in-1`/“6合1”等本地化等价事实，以及 FAQ/SKU 中未经支持的技术参数和实测宣称；
- 人工编辑保存前的服务端来源归属与事实复核；
- 内容工坊精简布局、离线边界提示、单项重新生成和 FAQ/SKU 编辑；
- 全部与单项重新生成的加载状态、成功提示和失败提示；
- 标题、卖点、详情、营销文案、FAQ、SKU、关键词和检查快照的全字段版本对比，恢复待确认与保存草稿待确认；
- 目标市场关键词语言检查、独立中文运营选词建议检查，以及包含完整内容章节的 Markdown 版本导出；
- 内容生成工具注册及工具清单；
- 前端统一认证客户端、草稿确认与版本恢复确认；
- 前端类型检查、构建和内容工坊路由。

提交前执行：

```powershell
cd backend
uv run ruff check src tests
uv run pytest -q

cd ..\frontend
npm run test:run
npm run typecheck
npm run build
```

若全仓类型检查报告非本功能既有错误，应记录准确文件和错误，不得将其描述为通过。

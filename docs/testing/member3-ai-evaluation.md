# 成员三 AI 评估方法

## 目标

该评估以固定合成数据验证智能选品、评论分析和商品内容生成，不以成功截图替代可重复运行的质量证据。

## 数据与边界

- 固定数据集：`data/evaluation/member3/v1/evaluation_cases.json`
- 数据集版本：`member3-eval-v1.0.0`
- 数据拆分：development、regression、demo
- 所有内容均为合成数据，不包含真实用户、店铺或 Shopee 数据
- 评论分析默认使用确定性规则
- 内容生成使用明确标记的 `offline_template`
- 未调用真实模型时 Token 和费用记为“不适用”，不得伪造为真实模型指标

## 实际运行

在 `backend` 目录执行：

```powershell
uv run sellpilot-evaluate-member3
```

默认生成 `docs/testing/member3-ai-evaluation-report.md`。需要机器可读结果时执行：

```powershell
uv run sellpilot-evaluate-member3 --json
```

## 指标定义

- 选品计算正确率：利润和利润率同时等于人工期望值的案例比例。
- 排序稳定率：输入次序改变后，稳定排序结果保持一致。
- 评论情感/主题正确率：规则输出包含人工期望标签的案例比例。
- 证据有效率：聚合证据是否全部引用本批输入评论。
- 结构化输出成功率：输出能否通过严格 Pydantic Schema。
- 商品事实一致率：受保护规格是否都出现在生成内容中。
- 合规检出准确率：危险声明和安全声明是否按人工期望识别。
- 幻觉率：当前固定集以事实检查失败比例计算。
- 多语言 Schema 分数：目标语言字段是否与请求一致，自然语言质量仍需人工复核。
- 重复运行稳定率：相同输入两次输出是否完全一致。
- 响应时间：本地固定评估的实际墙钟耗时。

失败不会被隐藏。每条失败均记录输入、期望、实际输出、版本、失败类型、修复状态和回归测试 ID。

# SellPilot v0.5.0 发布说明

SellPilot v0.5.0 是 AI 运营助手与跨模块工作流集成里程碑。该版本继续保持单用户、
单模拟店铺、PostgreSQL 和 Mock Shopee 边界，不代表真实 Shopee 或生产环境已经接入。

## 主要内容

- 中文优先的聊天式 AI 运营助手，支持规划、创建任务和创建并运行。
- Assistant Task 与 Task Center 联动，保留真实 Task、Step、ToolCall、Confirmation
  和 OperationLog。
- 订单、物流、低库存、补货建议、智能选品、评论分析、产品改良、内容生成、
  知识库检索和客服回复建议统一接入 TaskRunner、WorkflowRegistry 与 ToolExecutor。
- 写操作和高风险动作继续由 Confirmation 阻断，确认后通过现有恢复机制执行。
- PostgreSQL Mock 商业数据、知识库导入和 Windows 本地启动链路完成集成验证。

## 发布边界

- `PLATFORM_ADAPTER=mock`，不会连接或修改真实 Shopee。
- 内容和模型能力依赖已配置 Provider；离线模板会明确标记，不伪装成外部模型结果。
- 客服回复默认生成草稿；模拟发送仍需用户确认。
- 库存补货只生成建议，不自动调整库存。
- Vite 生产构建可能报告大 chunk 警告，当前为非阻塞项。

## 发布门禁

发布前必须通过：

```powershell
cd backend
uv run ruff format --check .
uv run ruff check .
uv run alembic heads
uv run alembic upgrade head
uv run alembic current
uv run alembic check
uv run pytest -q

cd ..\frontend
npm run format:check
npm run lint
npm run typecheck
npm run test:run
npm run build
```

本文件记录候选发布范围；最终 Tag 只能在 `develop` 经 PR 合入 `main` 并完成发布核验后，
由组长在对应 `main` 提交上创建。

# 评论分析前端调用

评论分析工作台位于 `/market/reviews`，通过统一 `request` 客户端访问
`/api/v1/review-analysis`。请求自动携带当前 Bearer Token，并明确区分后端未连接、
未登录、业务失败与空数据。

页面先按商品、站点、语言、评分和时间筛选评论，再创建并运行分析任务，最后分页读取
代表证据。当前只展示数据源已有译文；没有译文时明确提示未接入真实翻译服务。
主题筛选只提供产品、包装、文案、物流、服务和其他；它匹配结构化主题而不是执行原文
子串查询。高频痛点门槛为 `max(2, ceil(有效评论数 × 10%))`。
点击高频痛点时，页面固定查询 `topic` 类型证据，并通过 `label` 精确筛选对应主题，
避免将主题标签误当成证据类型。

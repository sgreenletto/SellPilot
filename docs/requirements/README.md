# Requirements

本目录用于维护 SellPilot 的需求基线、业务规则、范围边界和验收标准。

当前版本为 `0.1.0` Foundation Milestone，已建立公共后端和前端底座。首版的单用户、单模拟店铺和 Mock Shopee 边界保持不变。

后端实现公共配置、认证、数据库、任务/确认状态机、平台适配器契约、工具协议、最小 MCP 服务和 diagnostic LangGraph；前端实现公共布局、设计系统、组件库、Dashboard 和业务占位路由。市场数据、选品、评论分析、产品改良、商品内容、库存、订单、物流、客服和 RAG 的完整业务均未实现。

## 需求文档

- `member2-data-schema.md`：成员二模拟数据的字段映射、业务实体、关系、枚举、导入顺序和模块边界。该文档是后续业务表与导入服务的设计基线，不表示相关能力已经实现。

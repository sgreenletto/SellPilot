# 成员二前端验收说明

> 对应分支：`feature/commerce-management-ui`
> 数据边界：本地业务系统、公开/手工导入数据和 Mock Shopee 实验数据。
> 真实 Shopee 注册、授权及生产接口不属于本轮验收目标。

状态含义：

- **已实现**：页面及相应交互可以运行。
- **前端预演**：仅演示流程，不会写入后端或修改平台数据。
- **待后端接口**：界面保留真实边界提示，不伪造成功结果。

## 安全和真实性

- 页面始终标记 Mock/实验数据，不暗示真实 Shopee 已连接。
- 正式商品、库存和平台写操作不得绕过确认任务。
- 前端预演结果不代表数据库或平台执行结果。
- 后端不可用或接口缺失时，页面必须显示真实状态。
